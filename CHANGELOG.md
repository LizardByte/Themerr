## [v2026.1109.170140] - 2026-11-09

## ‼️ Attention: Themerr has moved!

The Themerr projects have migrated from the **LizardByte** GitHub organization to the **[Themerr](https://github.com/Themerr)** GitHub organization. Release checks, downloads, issue submission, and project links now point to the new home. ThemerrDB integration has also been updated for the move. ([#711](https://github.com/Themerr/Themerr/pull/711))

## ✨ Highlights

- **Retry individual themes.** Queue pending or failed themes directly from the Overview page without running a full theme scan. ([#692](https://github.com/Themerr/Themerr/pull/692))
- **Control startup scanning.** Disable **Scan on startup** under **Settings > Themerr** to skip the initial theme scan while keeping regularly scheduled scans enabled. ([#693](https://github.com/Themerr/Themerr/pull/693))
- **Updated translations and dependencies.** Includes refreshed translations and updates to the application’s dependencies.

## [v2026.1022.123038] - 2026-10-22

## ‼️ Attention: Final release supporting macOS 14

**This is the last Themerr release supporting macOS 14 (Sonoma).** Future releases will require a newer version of macOS.

## ✨ Highlights

- **Built-in MCP server.** Connect MCP-compatible clients to Themerr, with access token management directly in the web UI. ([#631](https://github.com/LizardByte/Themerr/pull/631))
- **More reliable Plex and Jellyfin dashboards.** Fix duplicate items and preserve items shared across multiple libraries, keeping counts and upload progress accurate. ([#627](https://github.com/LizardByte/Themerr/pull/627))
- **Complete Jellyfin library browsing.** Movies remain visible when Jellyfin groups them into collections. ([#639](https://github.com/LizardByte/Themerr/pull/639))
- **Improved startup reliability.** Fix configuration parsing errors that could prevent Themerr from starting. ([#630](https://github.com/LizardByte/Themerr/pull/630))
- **Reduced Docker disk activity.** Avoid repeatedly extracting the application bundle during startup and health checks, reducing unnecessary disk writes. ([#660](https://github.com/LizardByte/Themerr/pull/660))

For a comprehensive list of changes, see below.

## [v2026.1008.3030] - 2026-10-08

## ‼️ Attention: Themerr now supports Plex and Jellyfin!

Themerr-plex has been renamed to **Themerr**! Manage Plex and Jellyfin servers from the same standalone application, with shared library browsing, theme playback, and processing history. This release also provides a migration path from the older Themerr-jellyfin plugin. ([#600](https://github.com/LizardByte/Themerr/pull/600))

## ⚠️ Breaking changes and migration notes

- **Update launchers and Docker references.** Release archives now use the Themerr name. Launch `themerr`, or `themerr.app` on macOS, and update Docker deployments to `lizardbyte/themerr`. Preserve your existing configuration directory or `/config` volume to retain saved settings, server connections, and history.
- **Keep your existing credential encryption key.** Docker and headless installations use `THEMERR_TOKEN_KEY_FILE`. The previous `THEMERR_PLEX_TOKEN_KEY_FILE` name remains supported; use the same key file when changing the variable name. This key also protects saved YouTube cookies.
- **Review Jellyfin migration settings before connecting.** Connect through **Servers > Jellyfin** using a Jellyfin API key. By default, Themerr recognizes unchanged themes from the older Themerr-jellyfin plugin and removes that plugin and its repository after connecting. These preferences are available under **Settings > Jellyfin**.
- **Make Themerr reachable from Jellyfin.** Save a Themerr address on the connected server card so Jellyfin can install its connector. With Themerr's default self-signed certificate, use the connector repository on HTTP port `9495` and publish that port in Docker. Use an address reachable from the Jellyfin server; `localhost` inside another container refers to that container.
- **Older Plex plugin installations still require migration.** If upgrading from `v2024.813.13709` or earlier, follow the [standalone application migration notes](https://github.com/LizardByte/Themerr/releases/tag/v2026.1004.152244) before starting this release.

## ✨ Highlights

- **Jellyfin integration.** Add themes to movies, series, and collections on Jellyfin 10.11.x and stable Jellyfin 12.x starting at 12.1, including 12.2. Existing user themes are protected by default, with optional replacement and backups. ([#600](https://github.com/LizardByte/Themerr/pull/600), [#613](https://github.com/LizardByte/Themerr/pull/613))
- **Automatic Jellyfin connector management.** Themerr installs and updates the matching connector, waits for playback to finish before automatic restarts, and fixes connector replacement restart loops. ([#600](https://github.com/LizardByte/Themerr/pull/600), [#606](https://github.com/LizardByte/Themerr/pull/606))
- **Remote Plex cleanup over SSH.** Remove older uploaded themes, posters, and artwork through SFTP when Plex runs on another machine. Configure password or private-key authentication with server fingerprint verification directly from the updated server cards. ([#619](https://github.com/LizardByte/Themerr/pull/619))
- **Safer YouTube cookie storage.** Saved cookies are encrypted and masked in Settings, with explicit controls to reveal, replace, or clear them. Existing saved cookies are encrypted automatically when upgrading. ([#612](https://github.com/LizardByte/Themerr/pull/612))
- **Accurate ThemerrDB deployment status.** The deployment indicator now reads the timestamp from ThemerrDB's published metadata. ([#615](https://github.com/LizardByte/Themerr/pull/615))
- **Updated Docker packaging.** Docker images now use an Alpine runtime with the packaged Themerr application and bundled Jellyfin connectors. ([#625](https://github.com/LizardByte/Themerr/pull/625))

For a comprehensive list of changes, see below.

## [v2026.1004.152244] - 2026-10-04

## ‼️ Attention: Themerr-plex is back!

After being archived, Themerr-plex has been revived with a major rewrite since the last stable release in August 2024.

**Themerr-plex now runs as a standalone application alongside Plex Media Server. Upgrading from `v2024.813.13709` or earlier requires migration to the new application.** Installation, configuration, and Plex authentication have changed. ([#497](https://github.com/LizardByte/Themerr-plex/pull/497))

## ⚠️ Breaking changes and migration notes

- **Remove the old plug-in before starting the standalone application.** Stop Plex Media Server, remove the Themerr-plex bundle from its `Plug-Ins` directory, and restart Plex. Install the standalone release archive or Docker image, and keep Themerr-plex running to process library updates.
- **Complete the new account setup.** On first launch, use the one-time setup link shown in the console to create your Themerr administrator account. The default web UI is available at `https://localhost:9494`; its locally generated certificate may trigger a browser warning.
- **Reconnect Plex and configure your settings.** In **Servers**, select **Sign in with Plex**, then connect the servers you want to manage. Your Themerr administrator account protects the application; your Plex account authorizes server access. Review your processing, overwrite, and ignored-library settings in the new application.
- **Use the modern Plex metadata agents.** Theme processing supports **Plex Movie** and **Plex Series** libraries. Legacy metadata agents are no longer supported.
- **Check locked fields when migrating.** Older Themerr-plex versions may have left themes or collection metadata locked. Enable **Ignore locked fields** if you want Themerr to update those fields.
- **Plex data-directory access is needed for cleanup.** Theme uploads use the Plex API. Removing older uploaded themes, posters, or artwork also requires access to the server’s Plex data directory. If that directory is unavailable, disable the three **Remove unused** settings.
- **Docker requires persistent configuration and a token encryption key.** Persist `/config`, mount a private key file outside that volume, and set `THEMERR_PLEX_TOKEN_KEY_FILE`. Keep the same key when recreating the container.
- **YouTube extraction has changed.** Themerr now uses `yt-dlp`, with Deno bundled in release archives. If YouTube requires sign-in, the **YouTube Cookies** setting accepts a JSON cookie export.

See the [installation guide](https://docs.lizardbyte.dev/projects/themerr-plex/latest/about/installation.html), [setup and usage guide](https://docs.lizardbyte.dev/projects/themerr-plex/latest/about/usage.html), and [Docker instructions](https://docs.lizardbyte.dev/projects/themerr-plex/latest/about/docker.html).

## ✨ Highlights

- **A dedicated management interface.** Manage multiple Plex servers, inspect theme coverage, search and filter your libraries, and monitor scans and upload failures.
- **Persistent theme playback.** Listen while navigating the application, with seeking, volume, shuffle, repeat, and supported system media controls. ([#594](https://github.com/LizardByte/Themerr-plex/pull/594))
- **Better troubleshooting and customization.** Browse searchable logs with session history, choose automatic/light/dark appearance, and exclude libraries per server. ([#592](https://github.com/LizardByte/Themerr-plex/pull/592), [#593](https://github.com/LizardByte/Themerr-plex/pull/593), [#595](https://github.com/LizardByte/Themerr-plex/pull/595))
- **Desktop notifications.** Receive configurable alerts for new releases and increased theme coverage. ([#596](https://github.com/LizardByte/Themerr-plex/pull/596))
- **Broader installation choices.** Native x86-64 and ARM64 archives are available for Windows, Linux, and macOS, alongside Docker images.
